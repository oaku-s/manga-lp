# 修正ガイド｜炭火焼鳥 とりき（通常版サンプル）

対象ファイル：`samples/normal/index.html`

色とフォントはすべて `<style>` 冒頭の `:root` ブロックに集約してあります。
それ以降のCSSは `var(--〇〇)` を参照するだけなので、**見た目を変えるときは `:root` だけを触ります**。
色コードが `:root` の外に書かれている箇所はありません。

## 2. どこを何行直せばよいか

| やりたいこと | 直す場所 | 行数 |
|---|---|---|
| **フォントを変えたい** | `--font-base` | **1行** |
| **アクセント色を変えたい** | `--accent`（明るい側も揃えるなら `--accent-bright` も） | **1行**（2行） |
| **本文の文字色を変えたい** | `--text` | **1行** |
| **背景色を変えたい（ベースだけ）** | `--bg` | **1行** |
| **背景色を全体的に変えたい** | 「背景のバリエーション」ブロックの6行 | **6行** |
| ボタンだけ色を変えたい | `--accent-fill` を色コードに書き換え | 1行 |
| 「名物」バッジだけ色を変えたい | `--accent-fill` を分割するか、`.menu-feature::before` に直接指定 | 1行 |
| 見出しだけ明るさを変えたい | `--text-heading` | 1行 |
| 本文中の強調だけ変えたい | `--text-emphasis` | 1行 |
| 罫線を目立たせたい／消したい | `--border` ほか罫線ブロックの該当行 | 1行ずつ |

### 背景色について

元のデザインは微妙に異なる5段階の暗さを使い分けているため、
「背景を全部まとめて1行で」は構造上できません。
ただし該当6行が `:root` 内で連続した1ブロックにまとまっているので、
まとめて差し替えられます。

「とりあえず全体の印象を変えたい」場合は、`--bg` と `--accent` の2行から試すのが早いです。

## 3. 同じ色でも用途ごとに分けた箇所

元のCSSでは同じ色コードが複数の用途に使い回されていました。
そのまま1変数にまとめると「片方だけ変えたい」ができなくなるため、**用途ごとに別変数**にしています。
値は同じなので、分けたこと自体による見た目の変化はありません。

| 元の色 | 分割した変数 | 分けた理由 |
|---|---|---|
| `#2a1e0e` | `--bg-slot` / `--border` | 「写真枠の背景」と「セクションの区切り線」。背景を明るくしても罫線は暗いままにしたい、といった要望に対応するため |
| `#f0e4c4` | `--text-heading` / `--text-emphasis` | 「見出し」と「本文中の強調」。見出しだけ大きく変えることが多いため |
| `#f5ead0` | `--text-hero` / `--text-menu-name` | 「ファーストビューのキャッチ」と「名物の品名」。役割がまったく違うため |
| `#0d0b07` | `--bg-deep` / `--on-accent` | 「暗いセクションの背景」と「ボタン上に乗る文字色」。アクセント色を明るい色に変えると、文字色だけ別途調整が必要になるため |
| `#c87a30` | `--accent-label` / `--accent-line` / `--accent-fill` / `--accent-slot` / `--accent-hover` / `--accent-em` | ラベル文字・罫線・塗り・写真枠文字・ホバー・強調。「ボタンだけ」「ラベルだけ」の指定が来やすいため |

## 4. セクション識別子

各セクションに `data-section` を付与しています（全9箇所）。
修正依頼を受けたときに、どのセクションの話かを特定・集計するために使います。

| `data-section` | 要素 | 内容 |
|---|---|---|
| `hero` | `<section id="hero">` | ファーストビュー（店名・キャッチコピー・外観写真） |
| `empathy` | `<section id="empathy">` | 共感（こんな夜、ありませんか） |
| `about` | `<section id="about">` | 店主・About |
| `craft` | `<section id="craft">` | こだわり（仕入れ・炭） |
| `menu` | `<section id="menu">` | 名物・おすすめ（つくね） |
| `voice` | `<section id="voice">` | お客様の声 |
| `info` | `<section id="info">` | 店舗情報 |
| `cta` | `<section id="cta">` | CTA（予約・相談ボタン） |
| `footer` | `<footer>` | フッター（注記・コピーライト） |

既存の `id` はCSSが参照しているため、そのまま残しています。
CSSのセレクタは `id` 側、修正箇所の特定は `data-section` 側、という使い分けです。

## 写真の差し替え位置

参考までに、画像を入れる枠には `data-slot` を付けてあります。

| `data-slot` | 位置 | 想定する写真 |
|---|---|---|
| `hero` | hero | 店の外観・暖簾（縦 3:4） |
| `owner` | about | 店主の写真（4:3） |
| `craft` | craft | 備長炭で焼く串（4:3） |
| `menu` | menu | つくねと卵黄（4:3） |
